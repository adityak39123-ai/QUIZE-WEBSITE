# Quiz Website

A simple and interactive Quiz Website where users can test their knowledge through different categories and difficulty levels.

## Features

* Different quiz categories
* Multiple-choice questions
* Difficulty levels
* Timer-based quiz
* Automatic score calculation
* User-friendly interface
* Final score display

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Files

* `index1.html` – Main webpage
* `app.css` – Website styling
* `script.js` – Quiz functionality and logic

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index1.html` in any web browser.
4. Start the quiz and answer the questions.
